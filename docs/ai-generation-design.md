# 小剧场管理器 AI 生成扩展设计

本文记录“小剧场管理器”SillyTavern 插件后续接入外置 AI API 的功能设计。当前阶段只描述产品结构和交互边界，不涉及具体代码实现。

## 目标

插件新增一个“小剧场生成”能力：用户可以从当前 SillyTavern 聊天中选择上下文，按规则清洗正文，选择世界书和参考小剧场样例，然后由前端直接调用外置 AI API 生成新的小剧场。

生成结果优先进入浏览器内存中的草稿区，用户可以预览、编辑、删除、重新生成，再决定是否发送到小剧场管理器 Web。

## 总体流程

```text
选择聊天上下文
-> 可选正则裁剪/清洗
-> 选择世界书
-> 按标签随机抽取参考小剧场
-> 组装 prompt
-> 前端调用外置 AI API
-> 生成结果进入草稿区
-> 用户确认后保存到小剧场管理器 Web
```

## 设置页结构

设置按钮点开后，可以把原有设置迁移到“通用设置”，并新增多个 tab。

```text
API / 聊天正文 / 世界书 / 生成预设 / 通用设置
```

### API

用于配置外置 AI 服务。

- API Base URL
- API Key
- Model
- 请求格式，例如 OpenAI-compatible
- Temperature
- Max tokens
- 是否启用流式输出
- 测试连接

第一版建议优先支持 OpenAI-compatible API，方便接入 OpenAI、OpenRouter、LiteLLM、One API、本地兼容服务等。

注意：如果 API Key 存在前端插件里，它会存在浏览器环境中。这个方案适合个人使用；如果插件公开分发，应让用户填写自己的 Key。

### 聊天正文

用于配置默认从 SillyTavern 当前聊天中读取哪些内容，以及如何处理。

- 最近 N 条消息
- 指定楼层范围
- 当前选中文本
- 是否包含用户消息
- 是否包含 AI/角色消息
- 是否包含系统或旁白类内容
- 正则处理开关
- 正则规则列表
- 处理方式：删除匹配、只保留匹配、替换匹配
- 处理前/处理后预览

这里的重点是区分“原始聊天内容”和“实际发送给 AI 的上下文”。用户应能在发送前看到清洗后的结果。

### 世界书

用于管理小剧场生成专用的世界书内容。

建议不和 SillyTavern 当前世界书自动同步，而是维护插件自己的世界书库。

- 世界书列表
- 手动导入 ST 世界书
- 导入 JSON
- 手动新增或编辑条目
- 条目启用/禁用
- 按标签、关键词、角色筛选
- 本次生成默认使用哪些世界书
- 可选：根据聊天正文关键词自动匹配条目

第一版可以先做“手动选择世界书或条目”，自动匹配后续再加。

### 生成预设

用于配置生成策略和参考样例抽取规则。

- 参考小剧场标签筛选
- 标签匹配方式：包含任一标签 / 必须包含全部标签
- 随机抽取数量
- 是否排除最近使用过的样例
- 生成数量
- 输出格式要求
- 风格要求
- prompt 模板
- 是否把抽到的小剧场作为参考样例发送给 AI

这里的“参考小剧场”不是固定模板，而是给 AI 学习格式、节奏、叙事密度和角色互动方式的样例。prompt 中应明确要求 AI 不要复写样例原文剧情。

### 通用设置

保留当前插件已有设置，并放置不属于前面几个分类的配置。

- 小剧场管理器 Web 地址
- 默认保存行为：只保存在内存 / 生成后询问 / 自动发送到 Web
- 草稿是否持久化到 localStorage
- 插件界面显示偏好
- 日志开关
- 导入/导出插件配置
- 重置设置

## 生成工作区

生成出来的内容不应该放在设置页里。设置页只保存默认规则，真正的生成和预览应放在插件主面板里的“生成工作区”。

推荐主面板结构：

```text
小剧场管理器主面板
├─ 浏览：小剧场列表、搜索、标签筛选
├─ 生成：本次生成任务、预览、生成按钮
├─ 草稿：生成结果、编辑、保存、删除
└─ 设置：API、聊天正文、世界书、生成预设、通用设置
```

也可以用一个“生成小剧场”按钮打开弹窗或抽屉。

推荐生成弹窗布局：

```text
左侧：本次输入与规则
- 聊天范围
- 正则清洗
- 世界书选择
- 参考样例标签
- 随机抽取数量
- 生成数量

右侧：预览与结果
- 上下文预览
- 已选世界书预览
- 已抽取参考样例预览
- 生成结果草稿

底部：生成 / 停止 / 保存选中
```

## 草稿区

AI 生成结果先进入浏览器内存草稿区。

每个草稿建议包含：

- 标题
- 标签
- 角色
- 正文
- 来源上下文摘要
- 使用的参考样例
- 使用的世界书
- 生成时间

草稿操作：

- 编辑
- 保存到小剧场管理器 Web
- 插入当前聊天
- 复制
- 删除
- 重新生成

默认不建议生成后立刻入库，因为 AI 结果通常需要挑选和编辑。

## 参考样例随机抽取

用户可以选择一个或多个标签，例如 `xx` 和 `yy`，插件从已有小剧场中随机抽取指定数量的参考样例发送给 AI。

可配置项：

- 标签匹配方式：任一标签 / 全部标签
- 抽取数量：用户自定
- 是否允许重复：默认不允许
- 是否排除最近使用过的样例
- 是否只发送正文，或同时发送标题、标签、角色信息

样例在 prompt 中的定位应是“参考写法”，不是“复写内容”。

## 世界书策略

建议将“ST 世界书”和“小剧场生成世界书”视为两套内容。

```text
ST 世界书
-> 手动导入到插件世界书库
-> 用户选择本次使用哪些世界书/条目
-> 发送给 AI
```

这样不会被 ST 当前启用状态、触发规则或内部结构影响。后续可以增加“从当前 ST 世界书导入”或“按关键词自动匹配”，但不做自动同步。

## 设计原则

- 设置页负责默认配置，生成工作区负责本次生成。
- 原始聊天正文不等于发送给 AI 的上下文，发送前应可预览。
- 已有小剧场是参考样例，不是固定模板。
- 世界书以插件自己的生成知识库为主，不依赖 ST 自动同步。
- 生成结果先进入草稿区，由用户确认后再保存到 Web。
- 第一版优先做前端直连 OpenAI-compatible API，不引入后端生成服务。

## 第一版建议范围

- 新增设置页 tabs：API、聊天正文、世界书、生成预设、通用设置
- 新增主面板“生成”入口
- 支持选择聊天范围
- 支持正则清洗与预览
- 支持按标签随机抽取参考小剧场
- 支持手动选择插件世界书条目
- 支持前端调用 OpenAI-compatible API
- 支持生成结果进入草稿区
- 支持草稿保存到小剧场管理器 Web
